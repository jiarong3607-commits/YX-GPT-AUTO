# 批量素材图片自动生成

## 要解决什么

让内部使用者选择素材图文件夹、底板图文件夹、提示词 txt 文件和结果图文件夹后，程序自动按顺序批量生成图片。每张素材图结合本次选定的底板图和固定提示词生成图片，生成成功后自动保存到本地结果图文件夹，并继续处理下一张素材图。

## 内部使用者

- 公司内部项目负责人；
- 内部测试人员；
- 需要批量生成结课作业图片或类似素材图的人。

## 第一版做什么

- 选择一个素材图文件夹，里面包含 N 张素材图；
- 选择一个底板图文件夹，本阶段只使用其中 1 张底板图；
- 如果底板图文件夹有多张，第一版让用户选择本次使用的一张；
- 单独选择一个提示词 txt 文件；
- 选择一个结果图文件夹；
- 程序读取提示词 txt，按顺序处理每张素材图；
- 每张素材图结合选中的底板图和提示词生成图片；
- 每张素材图需要生成多少张，由提示词内容决定；
- 生成成功后自动保存到本地结果图文件夹；
- 某张素材或某次生成失败时，记录错误并跳过，继续下一张；
- 页面显示进度：总数、当前第几张、成功/失败、输出路径。

## 第一版不做什么

- 不做广告、支付、积分、订阅、定价、公开注册；
- 不做商业化产品流程；
- 不做复杂图片编辑器；
- 不做多人协作；
- 不做素材管理后台；
- 不做自动发布到外部平台；
- 不做多底板图自动组合批量生成；
- 不保存明文 API Key、Cookie、Token、Secret 或账号密码。

## 完成标准

- 可以选择素材图文件夹、底板图文件夹、提示词 txt 文件和结果图文件夹；
- 可以按顺序自动处理素材图文件夹里的所有素材；
- 可以按提示词要求决定每张素材生成数量；
- 每张成功生成的图片会自动保存到结果图文件夹；
- 单张失败不会中断全部任务，会记录失败原因并继续下一张；
- 跑完后能看到成功数量、失败数量、失败原因和结果保存位置；
- 不把真实 API Key、Cookie、Token、Secret 或账号密码写入代码、日志、普通文档或前端页面。

## 风险边界

这是高风险需求，因为涉及真实图片生成接口、API Key、批量自动调用、本地文件读写、额度和成本消耗。

必须遵守：

- 真实 API Key、Secret、Cookie、Token、账号密码不能进入代码、普通配置、日志、数据库、Issue、PR、Obsidian 或聊天记录；
- 批量生成需要避免无限循环、重复扣费、过量调用和覆盖已有结果文件；
- 本地文件读写只能处理用户明确选择的素材图、底板图、提示词 txt 和结果图文件夹；
- 如果后续接入登录、数据库、自动调度、生产部署或多账号调度，需要继续按高风险流程处理。

## 已确认默认规则

- 素材图来源：用户选择素材图文件夹；
- 底板图来源：用户选择底板图文件夹；
- 多张底板图处理：第一版不做自动组合，让用户选择本次使用的一张；
- 提示词来源：单独选择一个 txt 文件；
- 结果保存位置：用户选择结果图文件夹；
- 生成数量：每张素材图需要生成多少张，由提示词内容决定；
- 失败处理：某张素材或某次生成失败时，直接跳过并记录失败原因，继续后续任务；
- 结果命名：使用“素材名 + 底板名 + 序号”，避免覆盖已有结果。
