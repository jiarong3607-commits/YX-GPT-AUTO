# 结课作业图片生成原型

## 要解决什么

为 gpt-auto 做一个内部 GPT 车队图片生成网页，让内部使用者可以在网页选择车队，进入 GPT 图片生成聊天页，输入提示词后生成并展示图片。

## 设计网页网址

- `yx.gptvip.com`

## 谁在内部使用

- 公司内部项目负责人；
- 内部测试人员；
- 参与结课作业演示的人。

## 第一版做什么

- 网页选择车队；
- 进入 GPT 图片生成聊天页；
- 输入提示词；
- 生成并展示图片；
- 显示侧边栏运行状态；
- 做后端参数校验；
- 记录非敏感运行日志；
- 支持 `DEMO_IMAGE_MODE` 演示模式，便于无真实 API Key 时验证原型；
- 支持内部访问码登录/会话。

## 第一版不做什么

- 不做广告、支付、积分、订阅、定价、公开注册等商业化功能；
- 不做复杂账号自动分配、回收、轮换规则；
- 不做完整管理后台；
- 不做多角色权限体系；
- 不做生产级监控、审计和异常恢复；
- 不保存明文账号密码、Cookie、Token、API Key 或 Secret。
